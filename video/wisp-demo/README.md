# WISP: 5-minute illustrated demo film (Remotion)

A five-minute product demo of WISP for the Tencent Cloud AI CAN DO IT Hackathon Singapore 2026 (Healthcare Case Study 1). It is illustrated 2D/2.5D animation built in Remotion, with real WISP app screens, ElevenLabs narration and an original score.

| Deliverable | File |
|---|---|
| Final film (1920×1080, 30 fps, 300 s, H.264 + AAC) | `wisp-demo.mp4` |
| Poster (also baked in as frame 0) | `wisp-demo-poster.jpg` |
| Contact sheet (two frames per scene) | `contact-sheet.png` |
| Narration by scene and timestamp | `voiceover-script.md` |
| Sidecar subtitles | `wisp-demo.srt` |
| Scene descriptions, transitions, assets | `storyboard.md` |
| What is real, illustrated or unvalidated, and how each tool was used | `PRODUCTION_NOTES.md` |

> **v2 (ad-style):** all 15 narration clips; kinetic type, spring UI, brand transitions and a 96 BPM score. Three motion-graphic inserts (brand ident, safety principle, end card) are built and rendered with **HyperFrames** in `hyperframes/` (`./hyperframes/sync-and-render.sh`) and composited into the Remotion timeline via `src/components/Insert.tsx`.

## Setup and render

Requires Node 20+, ffmpeg and ffprobe. The music script uses the repo's `services/.venv` (numpy and scipy).

```bash
cd video/wisp-demo
npm install
npm run prepare-audio                                   # probe narration clips → src/data/vo.json (subtitle timings, ducking)
npm run srt                                             # sidecar subtitles → wisp-demo.srt
../../services/.venv/bin/python -I scripts/make_music.py # score + UI tones → public/audio/
npm run studio                                          # preview in Remotion Studio
npm run render                                          # → out/wisp-demo-video.mp4
./scripts/finalize.sh                                   # loudness, poster frame, contact sheet → wisp-demo.mp4
node scripts/stills.mjs --sheet work/sheet.png 5 60 140 # review stills (seconds) from one bundle
```

Re-capture the app screens (optional). This uses the web app's isolated e2e stack and leaves `data/` and the :8787/:3000 demo untouched:

```bash
cd apps/web
cp ../../video/wisp-demo/capture/capture.spec.ts e2e/_capture.spec.ts
npx playwright test e2e/_capture.spec.ts; rm e2e/_capture.spec.ts
```

```
  components/

    Rooms.tsx           LivingRoom (parallax layers), SensingRoom, SideChair, Router, Laptop
    WispSense.tsx       WISP Sense concept device (2.5D, yaw-driven shading) + its honesty tag

    Wordmark.tsx        lowercase "wisp" wordmark with line arc, leaf and amber point
    Phone.tsx           phone frame showing real screenshots, crossfades, tap ripples
    Signal.tsx          illustrative Wi-Fi link that bends with movement / scatters with noise
    Motion.tsx          motion toolkit: springs, kinetic type, blobs, bursts, 3D float, camera moves
    Shots.tsx           shot system on @remotion/transitions + brand transitions (blob wipe, zoom-through, line sweep)
    Insert.tsx          plays a HyperFrames-rendered insert (public/hf/*.mp4)
    Soundtrack.tsx, Card.tsx, Icons.tsx, Type.tsx, Paper.tsx
  scenes/S1.tsx … S9.tsx
public/screens/         real app captures (3× DPR)
public/audio/           vo/ (ElevenLabs), sfx/, music.wav
scripts/                prepare-audio.mjs, make-srt.mjs, make_music.py, stills.mjs, finalize.sh
hyperframes/            HyperFrames projects for the three inserts (ident, principle, endcard) + sync-and-render.sh

```

## Changing things

- **Timing:** scene boundaries are in `SCENES` in `src/Root.tsx`, and narration placement is in `src/data/script.json`. After editing, run `npm run prepare-audio`.
- **Narration:** drop `public/audio/vo/<id>.mp3`, then run `npm run prepare-audio`. Subtitle timings realign to the clip's pauses and the music ducks around it automatically.
- **Honesty labels** (`Tag`, `SenseTag`) are part of the content. Keep them wherever real and illustrated material meet.
